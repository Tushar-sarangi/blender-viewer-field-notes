# Frame / Field — Blender Viewer Showcase

**Open the live browser viewer:** [tushar-sarangi.github.io/blender-viewer-field-notes](https://tushar-sarangi.github.io/blender-viewer-field-notes/?v=a2fd3bf)

Jump straight to the animated default cube: [First Lift](https://tushar-sarangi.github.io/blender-viewer-field-notes/?scene=cube&v=a2fd3bf).

The landing page embeds the orbitable viewer at figure scale. Choose one of three scenes, then drag to orbit, scroll to zoom, and use the viewer's Play, Loop, and timeline controls.

## Examples

- **Lantern Ridge** — an amber-lit courier crosses an A.N.T. Landscape mountain range. [Open in the live viewer](https://tushar-sarangi.github.io/blender-viewer-field-notes/?scene=lantern&v=a2fd3bf) · [Download the editable scene](assets/lantern-ridge.blend)
- **Paper Moon** — a signal probe moves over a layered dusk landscape. [Open in the live viewer](https://tushar-sarangi.github.io/blender-viewer-field-notes/?scene=moon&v=a2fd3bf) · [Download the editable scene](assets/paper-moon-signal.blend)
- **First Lift** — the Blender default cube rises on Z, returns to its start, and loops with stepped object-action keys. [Open in the live viewer](https://tushar-sarangi.github.io/blender-viewer-field-notes/?scene=cube&v=a2fd3bf) · [Download the editable scene](assets/default-cube.blend)

The viewer and scenes are bundled on this Pages origin, so visitors do not need access to the private source repository. See [blender-viewer.docs.md](blender-viewer.docs.md) for supported animation data and limitations.
